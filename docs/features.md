# 功能细节

> 项目总览、构建和快速开始见 [README](../README.md)。

## 世界与渲染

- **流式世界**：以玩家为中心动态加载/卸载 `16 x 64 x 16` 区块，水平方向无限延伸。
- **后台线程**：TBB 并行地形生成与网格构建，主线程只负责 GL 上传（每帧预算 8 个）。
- **渲染**：视锥剔除、距离雾、程序化 8×8 贴图集（带 padding + mipmap）、顶点 AO、
  半透明水面/传送门独立 pass、天空穹顶 + 太阳 + 星空。
- **地形**：OpenSimplex2 + 4 层 fBm，海平面/沙滩/草地/水体，跨区块确定性树木。
- **时间**：昼夜循环、日落暖色、夜间星空与全局光照衰减。
- **方块**：草、土、石、沙、原木、树叶、木板、圆石、水、砂砾、石砖、红砖、雪块、黑曜石、
  地狱岩、灵魂沙、萤石、基岩、熔岩、地狱砖；另有不可放置的传送门方块和火焰。

## 玩法

- **玩家物理**：AABB 碰撞，重力/跳跃/游泳/创造飞行/双击 `W` 奔跑。
- **交互**：DDA 射线拾取、破坏/放置/取色、选中描边、9 格热键栏。
- **创造物品栏**（`E`）：仿原版的分类标签 + 9×5 物品网格 + 滚动条 + 搜索框 + 快捷栏行 +
  销毁槽；方块以等轴 3D 图标显示，物品用平面图标，单击拿起、Shift+单击整组入栏、
  `1`–`9` 直接放入快捷栏。
- **物品系统**：快捷栏每格可以放一个方块或一个物品；物品有独立的定义（名称、图标、堆叠上限）
  和存档字段，为后续工具/食物留好接口。
- **打火石**：创造物品栏 `Tools & Utilities` 分类；对着合法黑曜石框架的内侧右键点燃
  2×3 到 21×21 的传送门（4×5 起步）；对着其他实心地面右键则点燃一格火焰。
- **火焰**：两张交叉半透明面渲染，走自发光 pass，夜间也可见；约 10 秒后熄灭，
  失去下方支撑或相邻有水会立刻扑灭；不蔓延、不伤害（创造模式）。
- **音频**：程序化合成的脚步/破坏/放置/跳跃/落地/点火/蒸发声（miniaudio，纯 2D 混音）。

## 传送门与地狱

- **传送**：站进传送门约 1 秒，按原版 8:1 换算 X/Z（Y 不变）。
- **落点**：在以落点为中心、水平 ±16 格、任意高度内找门方块；找到就复用，否则自动在地面/
  洞壁里凿出空间并新建一座 4×5 门框（内 2×3）；建门失败时直接落在 y=48。
- **没有固定配对**：传送是坐标换算 + “扫描到的第一块”门方块复用，不是门与门一对一。
  多个门可能共用落点，从偏移落点返回时可能新建一座门。详见
  [已知限制](roadmap.md#已知限制)。
- **传送门方块**：内侧紫色方块可左键逐格打掉，剩下的残块仍然会传送；黑曜石框保留。
  门方块不能中键取色或放置。
- **地狱维度**：独立地形、天空、方块和编辑；每个维度各自保存玩家位置/朝向与方块编辑。

## 地狱地形

压缩到 64 高：

- y=0 基岩底、y=63 基岩顶
- 地狱岩台地，高度限制在熔岩海附近
- y≤12 熔岩海
- 灵魂沙斑块、顶部萤石簇
- 暂无洞穴（按计划是下一步）

## 流体

- **20 Hz 模拟**：水每 5 tick、岩浆主世界 30 tick / 地狱 10 tick 更新一次；每 tick 预算 512 格。
- **流动规则**：优先下落成柱，否则水平扩散；水 7 格，岩浆主世界 3 格、地狱 7 格；
  断源后从远端逐级干涸。
- **高度**：源头 1.0 格，下落 1.0 格，流动等级每级降低 1/8 格；网格会裁掉相邻等级之间的
  内部面，只露出台阶侧壁。
- **细节**：水在地狱瞬间蒸发；水碰岩浆时源岩浆→黑曜石、流动岩浆→圆石（水保留）；
  水下雾和游泳判定按实际液面高度计算。
- **未做**：无限水、石头细分、角点平滑水面；流动在未加载区块边界暂停，加载后唤醒。

## 存档与设置

- **存档**：zlib 压缩的二进制格式，只保存玩家编辑 diff + 玩家状态 + 分维度状态；
  `F5`/`F9`/退出自动存档，启动时自动读取 `save.aimc`。
- **设置**：视距、FOV、灵敏度、音量、昼夜长度、VSync、HUD、自适应视距。
- **启动模式**：正常游戏、`--shot` 无头截图、`--benchmark` 帧率测试；详见
  [开发与测试](development.md)。
