# 操作与按键

> 构建、启动参数和截图模式见 [开发与测试](development.md)。

| 按键 | 作用 |
|---|---|
| `WASD` | 移动（**双击 `W` 奔跑**） |
| `Space` / `Shift` | 跳跃、飞行上升 / 飞行加速 |
| `F` | 切换创造飞行 |
| 鼠标 | 视角 |
| 左键 / 右键 / 中键 | 破坏 / 放置（或使用手持物品）/ 取色选块 |
| 手持打火石 + 右键 | 点燃黑曜石框架，生成传送门；普通实心地面则点火 |
| `1`–`9` / 滚轮 | 选择方块 |
| 左键点击水源/岩浆源 | 移除源头（流动格不挡准星） |
| `E` | 打开/关闭创造模式物品栏 |
| `F1` | 打开/关闭设置面板（打开时释放鼠标） |
| `F5` / `F9` | 快速存档 / 读档 |
| `M` | 静音 |
| `Esc` | 关闭面板；面板已关时退出 |

补充：

- 进入游戏后鼠标会被捕获；按 `Esc` 或打开面板会释放。
- 启动时如果存在 `save.aimc` 会自动读取；`--new` 或 `--seed` 会开新世界。
- 创造模式没有生命值/饥饿值，岩浆和火焰不会造成伤害。
- 传送门约 1 秒触发；传送后有 2.5 秒冷却，避免立刻回弹。
- 紫色传送门方块可以用左键逐格打掉；残块仍然可用，黑曜石框不会被破坏。
- 打火石在地面点燃的火焰约 10 秒后熄灭，水或失去下方支撑会立刻扑灭。
