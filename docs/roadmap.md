# 已知限制与路线图

> 功能和操作见 [功能细节](features.md)、[操作与按键](controls.md)。

## 已知限制

- 单一生物群系，没有洞穴/矿脉/结构
- 流动水面是每格 1/8 的台阶，尚未做角点平滑/连续斜坡；没有水下折射/焦散
- 源头仍是整格（1.0）高度；没有无限水；水岩反应只有黑曜石/圆石，没有石头细分
- 流体在区块未加载的边界处暂停，区块重新加载后会被唤醒继续
- 没有生物、合成、红石、方块光照传播（只有 AO + 天光近似）
- 地狱暂时没有洞穴、堡垒/遗迹和生物
- 岩浆不掉血（创造模式）；地狱里的水会蒸发
- 打火石不消耗、没有耐久；火焰不蔓延、不伤害、不提供方块光照
- 传送门没有固定配对：坐标换算 + 水平 16 格内“第一块”门方块复用，不检查 Y 距离；
  从偏移落点返回时可能生成一座新门
- 传送门重新点燃要求门内全是空气；打掉一格后残留的门方块需要清完才能重新点
- 存档只保存编辑；修改地形生成算法会让旧存档的地形变化
- 没有区块 LOD、间接绘制、阴影贴图
